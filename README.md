# Ghosts of Asia

Animated YouTube Shorts series: one Asian ghost legend per day, told in two parts.

- `PLAYBOOK.md` — how each daily episode is made and posted
- `toolkit/` — shared drawing, voice and render code
- `episodes/` — each episode's script, art and sound, plus `LOG.md`
- `videos/` — finished Shorts (hosted here so the scheduler can fetch them)
